# Resource Center

Application web de démonstration pour la gestion des réservations de ressources.

## Lancement avec Docker Desktop

```bash
docker compose up --build
```

Puis ouvrir : http://localhost:8080

## Fonctionnalités de base

- page d'accueil inspirée du design fourni ;
- navigation de base avec bouton de changement de langue ;
- détection automatique de la langue à partir du navigateur ;
- bouton de langue FR / EN ;
- pages et composants non redirigeants pour l'instant.
